# V03 with three required timeline entries

This closed control uses the v27 request and the same V03 source-version
and citation IDs. Preflight requires exact JSON equality after adding
`minItems: 3` to the timeline array. The bound applies only to synthetic
V03 in the opted-in citation test with the reviewed ledger and bank
statement selected. The workflow still checks the event kinds, times,
citations and evidence linking the documents.

One attempt uses Groq Free, Qwen without reasoning and a 1,000-token
completion limit. The guarded HTTP transport reserves every attempt
before sending it and keeps only the exception type on a network failure.
The frozen V3 reference and the proposal's validation result both gate
the six-case acceptance. Existing data and decisions are outside the
two new test databases.

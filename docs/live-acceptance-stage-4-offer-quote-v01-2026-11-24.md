# Контроль V01 с цитатой об отправке предложения

Перенос цитаты прошёл офлайн на сохранённом ответе v40. Декодер использует текст предложения, уже выбранный моделью для факта, если событие ссылается на отметку отправки из того же письма и время совпадает. Без цитаты, при другой отметке времени или ссылке на другой источник перенос пропускается. Правило работает в тестовом профиле V01. [Офлайн-проверка](../evals/live/v41-groq-gpt-oss-20b-offer-quote-v01-2026-11-24/offline-gpt-oss-verification.json).

В новом контроле v41 Groq принял строгую схему и вернул HTTP 200. Модель оставила хронологию и список цитат пустыми. Приложение добавило из проверенного журнала получение письма и предложило открыть непрочитанный оригинал. Принятие альтернативы осталось неподтверждённым. Для события отправки исходный ответ не содержал ни события, ни выбранной цитаты. Проверка приложения прошла, эталон зафиксировал пропуск `alternative_offered`. Серия V01–V06 не запускалась. Этап 4 остаётся открытым. [Сверка карточки](../evals/live/v41-groq-gpt-oss-20b-offer-quote-v01-2026-11-24/ablation-V01/review.json).

Отправлен один запрос к GPT‑OSS 20B на Groq Free с `reasoning_effort=low`. Тело запроса совпадало с v40. Бюджет $0, повторов ноль, 4 293 токена по ответу Groq. Стенд остановлен. Сверены 826 защищённых файлов, состояния 51 прежнего контейнера и хеши трёх томов, включая основную БД. Прошли 485 тестов Python с PostgreSQL, 21 тест замороженной базы и 11 сценариев Chromium. Replay сохранил отдельные исходную карточку, операторскую правку и решение без вызова модели. [Архив](../evals/live/v41-groq-gpt-oss-20b-offer-quote-v01-2026-11-24/manifest.json), [сохранность](../evals/live/v41-groq-gpt-oss-20b-offer-quote-v01-2026-11-24/preservation.json).

Следующий кандидат — `timeline.minItems=1` только для V01 с однозначно связанным письмом. В локальном Ajv условие отклонило пустой ответ v41 и пропустило сохранённые ответы v34 и v40. Наличие события само по себе оставляет открытым вопрос, что именно процитировала модель. Живой контроль должен проверить событие отправки и его доказательство по прежнему эталону. [Проверка ограничения](../evals/live/v41-groq-gpt-oss-20b-offer-quote-v01-2026-11-24/offline-v01-empty-timeline.json).

## Что ещё требуется для закрытия

Зафиксировать одну запускаемую конфигурацию Groq Free и повторить
ограниченную приёмку на шести условиях. Это может быть один профиль
с выбором инструкции по снимку конкретного кейса. Он должен давать
одинаковое поведение на этом кейсе независимо от настроек других.

Сейчас [выбор инструкции](../src/proofline/providers/live.py#L82)
проверяет наличие настроек во всём экземпляре. Когда в одну конфигурацию
сложены разметки и разрешённые источники из шести архивов, ни одна из
шести системных инструкций не совпадает с ранее принятой для этого
кейса. Кроме того, [seed](../src/proofline/application/seed.py#L32)
создаёт новые ID версий источников. Разметку нужно привязывать заново
по проверенным ID источника и хешу текста.

Приёмку закрывает новый протокол одного стенда с зафиксированными
обновлёнными настройками, SDK, схемой и бюджетом. Каждый кейс получает
явный результат, а HTTP 400/429 и пропущенные события остаются в
отчёте. [План отдельного публичного демо и полное саморевью](solution-review-2026-11-18.md).

# Контроль V05 с подсказкой о времени уведомления

**Groq отклонил единственную попытку с HTTP 403.** Карточка и данные о
расходе токенов отсутствуют. Качество ответа с новой подсказкой ещё не
проверено. Этап 4 остаётся открыт. Провайдер не вернул более точный код
отказа. Приложение сохранило `PROVIDER_ACCESS_DENIED`.
[Архив v30](../evals/live/v30-groq-qwen-v05-notice-control-2026-11-19/manifest.json).

Тариф Free подтверждён актуальным скриншотом Billing. График Activity
показал достаточный запас даже при использовании самого высокого столбика.
Проверка учитывала ранее измеренный предел в 1 000 выходных токенов и
публичные дневные лимиты модели. Бюджет $0, модель
`qwen/qwen3.8-27b`, `reasoning_effort=none`, повторов ноль.
[Запись проверки квоты](../evals/live/v30-groq-qwen-v05-notice-control-2026-11-19/quota-console.json),
[лимиты Groq](https://console.groq.com/docs/rate-limits).

В запросе V05 по сравнению с v29 изменился только текст системной инструкции.
Подсказка указывает на время исполненной операции из журнала поставщика и
учитывает отдельное время отправки уведомления. Она включается в тестовом
профиле при совпадении отметки об отмене с выбранным источником. На прежних
снимках остальные пять запросов совпали полностью. Схема, ID цитат и вход
V05 сохранились.
[Проверка запроса](../evals/live/v30-groq-qwen-v05-notice-control-2026-11-19/preflight.json),
[запись HTTP 403](../evals/live/v30-groq-qwen-v05-notice-control-2026-11-19/full-V05/wire.json).

Прошли 470 тестов Python, 21 тест замороженного набора, проверка схемы
и локальный Replay walkthrough. Контрольный стенд остановлен. Сверены
599 защищённых файлов, состояния 40 прежних контейнеров и содержимое
тома v29. Для продолжения нужен доступ к API Groq с закрытого стенда.

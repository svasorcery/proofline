# Проверка ограничений на V01

17 ноября 2026 года выполнен один согласованный запрос на Groq Free.
Groq принял временную схему со `strict=true`. Qwen `medium` вернул
единственный запрошенный факт и предложил открыть нужное письмо. Повторов
не было. Согласованный бюджет $0, стоимость в ответе приложения `null`.
[Квоты Groq](https://console.groq.com/docs/rate-limits).

| Проверка | Результат |
| --- | --- |
| Временная схема `assembly-choices-v1` | Принята. Ответ завершился с `finish_reason=stop` и прошёл проверку формата. |
| Письмо | `read_source` по ожидаемому адресу `1618ae5e5b894145` с требованием `original_acceptance_reply`. |
| Факт | Только `alternative_acceptance=unconfirmed`. |
| Хронология | Предложение отправлено в 09:10, ответ получен в 09:36. Оба события подкреплены цитатами. |
| Дословность | 11 из 11 фрагментов найдены однозначно в источниках. |
| Хранение | Исходный текст ответа и преобразованная карточка сохранены отдельно. |
| Статус карточки | Нужна проверка оператора. Блокировок и операторского решения нет. |

V01 соответствует варианту без оригинала письма из замороженного набора.
Оригинал исключён из снимка, в запрос попал только адрес с метаданными.
Это единственный разрешённый источник для нового запроса, при этом модель
могла выбрать просьбу к оператору. Она выбрала именно открытие письма.
Почтовый журнал подтверждает получение ответа. Содержание согласия модель
оставила неподтверждённым до чтения оригинала.

Использовано 4 311 токенов, из них 2 665 входных и 1 646 выходных. В выходные
входят 1 024 reasoning-токена. Текст запроса собран из изолированной БД до
запуска и совпадает по SHA256 с запросом в записи запуска. [Архив](../evals/live/v7-groq-qwen-choices-2026-11-17/manifest.json).

После запроса Live выключен, ключ удалён, новый проект остановлен с
сохранением своей БД. Совпали хеши семи защищённых томов и 184 файлов.
Состояния четырнадцати прежних контейнеров совпали до и после.

Следующий шаг — отдельно согласовать V02 и V04 на том же профиле без
подходящих непрочитанных источников. На V02 проверить, попросит ли модель
оригинал и подтверждение доставки и вернёт ли отдельное событие отправки.
На V04 проверить, останутся ли ровно один запрошенный факт, два нужных
подтверждения и полноценные цитаты для событий. Успех V01 подтверждает
совместимость временной схемы для этого обращения и выбор письма.

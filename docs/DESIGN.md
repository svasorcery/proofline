# Operator interface

An operator reads source documents at a desk during daylight. A light background supports prolonged reading and comparisons between documents.

Use a restrained palette: cool neutral page and panel surfaces, dark ink, petrol for selected items and primary actions, amber for review, red for blocking issues and muted green for an explicit current decision. Status always has a text label.

Typography uses Segoe UI and platform sans-serif fallbacks. Body text is 15px with comfortable line spacing; source text preserves whitespace. Labels and tables are compact, with clear heading levels. No external font request is required.

The case list uses rows. The workspace has a case heading and action toolbar above a split analysis/document view, with checks and the operator decision below the analysis. Narrow layouts switch between analysis and source without dropping the selected evidence. Full borders and tinted backgrounds distinguish state, with no decorative side stripes.

Use native buttons, inputs, selects, textareas and disclosures. Primary actions are solid petrol; destructive decisions use explicit wording. Disabled controls include nearby explanatory text. Focus is visible; only state transitions animate, respecting reduced motion.

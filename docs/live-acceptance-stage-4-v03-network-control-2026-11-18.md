# Контрольный V03 после ошибки соединения

**Groq принял запрос. Карточка не прошла проверку качества.** Один вызов
на Groq Free с `qwen/qwen3.8-27b`, `reasoning_effort=none` и потолком
1 000 токенов. Бюджет $0, повторов нет. Условие для запуска V01–V06
не выполнено. Этап 4 остаётся открыт.
[Архив v27](../evals/live/v27-groq-qwen-v03-network-control-2026-11-18/manifest.json).

На свежем стенде восстановлены ID версий источников V03 из v26, чтобы
воспроизвести всё тело запроса, включая ID цитат. SHA256 JSON совпал
с ранее отправленным `220eeb7a…ff7`. Groq вернул HTTP 200 и 171 выходной
токен. Сетевой ошибки в этой попытке не было. На имитированных ошибках
соединения и чтения тела проверена запись типа ошибки без сообщений SDK
и заголовков запроса.
[Предзапусковая сверка](../evals/live/v27-groq-qwen-v03-network-control-2026-11-18/preflight.json),
[сетевой результат](../evals/live/v27-groq-qwen-v03-network-control-2026-11-18/full-V03/wire.json).

Модель верно определила зачисление возврата и связала журнал с выпиской.
Все шесть цитат дословны. В карточке отсутствуют списание, запуск возврата
и зачисление в хронологии. Валидатор сохранил исходный ответ и карточку,
заблокировал одобрение и записал причину `required_timeline_event_missing`.
[Проверка карточки](../evals/live/v27-groq-qwen-v03-network-control-2026-11-18/full-V03/review.json).

Локальная сверка Ajv показала, что строгая схема запроса допускает пустую
хронологию. В пробной копии схемы `timeline.minItems=3` отклонил
текущий пустой ответ и вариант с двумя событиями. Ранее принятый ответ
с тремя событиями прошёл после сопоставления ID цитат. Для продолжения
нужно подключить это ограничение только для V03 с проверенными
источниками. Приложение продолжит проверять сами события и их цитаты.
[Офлайн-проверка схемы](../evals/live/v27-groq-qwen-v03-network-control-2026-11-18/offline-timeline-shape.json).

Стенд остановлен. Сверены 518 защищённых файлов и состояния 37 прежних
контейнеров. Содержимое тома v26 проверено по хешу до и после.
[Сохранность](../evals/live/v27-groq-qwen-v03-network-control-2026-11-18/preservation.json).

# Сборка доказательств из проверенных записей

В закрытом тестовом профиле приложение берёт на себя хронологию V02 и V03, если разметка однозначно совпадает с текущими источниками. Оно копирует точные цитаты и метки времени из снимка. Для подтверждённого возврата приложение связывает журнал с выпиской по общей банковской трассе. Модель сохраняет свои выводы о фактах и вопросы о том, чего не хватает.

Типы событий, уже собранных приложением, исключаются из схемы ответа модели. Модель может указать другие события. Исходный ответ хранится отдельно от карточки. Изменённые и исключённые источники, повторяющиеся цитаты и конфликтующие времена проверены офлайн. Если модель считает возврат незавершённым, а выписка подтверждает зачисление, карточка показывает противоречие и блокирует одобрение. [Подтверждение проверок перед запуском](../evals/live/v48-groq-gpt-oss-20b-reviewed-assembly-2026-11-25/validation-complete.json).

# Проверка этапа 4 с компактным ответом V04

В закрытом профиле V04 приложение собирает три события из связанных проверенных источников. Отправка предложения зафиксирована в 12:10, отправка ответа клиента в 12:25, получение ответа в 12:27. Groq получает строгую схему из трёх полей `facts`, `readiness`, `follow_up`. Приложение подставляет идентификатор кейса и хронологию в карточку, сохраняя ответ модели отдельно. При исключении одного из источников или нарушении порядка событий используется полный формат. Тела запросов остальных пяти кейсов совпадают с v48. [Офлайн-проверка](../evals/live/v50-groq-gpt-oss-20b-v04-compact-control-2026-11-25/offline-reviewed-assembly.json).

В отдельном контроле v50 Groq вернул HTTP 200. Модель распознала условное согласие и попросила только подтверждения тихого номера и окон во двор. Все семь фрагментов карточки дословно присутствуют в источниках. [Контроль V04](../evals/live/v50-groq-gpt-oss-20b-v04-compact-control-2026-11-25/full-V04/review.json).

## Одна серия V01–V06

На втором закрытом стенде тот же профиль обработал все шесть кейсов. Groq вернул HTTP 200 на каждый запрос. Пять карточек прошли исходные критерии. [Итог v51](../evals/live/v51-groq-gpt-oss-20b-stage4-acceptance-2026-11-25/summary.json).

| Кейс | Проверка качества |

| V02 | Прошёл. Собраны отмена, отправка и получение сообщения. |
| V03 | Прошёл. Подтверждены три платёжных события и связь журнала с выпиской. |
| V04 | Прошёл. Три события восстановлены по источникам, модель запросила два недостающих подтверждения. |
| V05 | Прошёл. Отправка отказа, получение поставщиком и отмена разделены по времени. |
| V06 | Не прошёл. Факты и хронология верны. Для снятия резерва отсутствует цитата об отсутствии списания, а модель запросила лишнюю банковскую выписку. [Разбор V06](../evals/live/v51-groq-gpt-oss-20b-stage4-acceptance-2026-11-25/full-V06/review.json). |

Этап 4 остаётся открытым до прохода всех шести карточек в одной серии. Проверка приложения пропустила V06, хотя эталон выявил неполное доказательство и лишний запрос. В платёжном журнале уже есть факт снятия резерва и явная запись об отсутствии списания и возврата. Офлайн на копии V06 проверены обе правки. Добавление только цитаты или только исправление следующего шага оставляет карточку за порогом эталона. Вместе правки дают проход. Ближайшая работа — проверить правило для V06 на полной записи, на неполной записи и при противоречащем списании, сохраняя необходимость запроса документа там, где исход неизвестен.

# Qwen medium на Groq Free

17 ноября 2026 года выполнены два согласованных запроса, V02 и затем V04.
Оба завершились с `finish_reason=stop` и прошли JSON Schema. Полный порог
качества остался **0/2**. Приложение заблокировало V02. V04 дошёл до ручного
review, где у одного события оказалось недостаточно доказательств.

Сравнение выполнено с [Qwen без явного effort](live-acceptance-qwen-2026-11-17.md).
В Chat-шаблоне добавлено только `reasoning_effort=medium`. Бизнес-входы, инструкция
v3.2, строгая схема, лимит 4096 и критерии совпали. Новый экземпляр использовал
прежний локальный образ и отдельную копию текущих исходников, смонтированную
для чтения. Перед запросами экземпляр подтвердил модель, effort и хеш шаблона.
Доступ и квоты основаны на подтверждении Free-аккаунта и документации Groq.
Одобренный бюджет $0. Приложение сохранило стоимость как `null`.
[Параметр reasoning](https://console.groq.com/docs/api-reference#chat-create-request-body).
[Квоты](https://console.groq.com/docs/rate-limits).

| Критерий | Qwen без явного effort | Qwen medium |
| --- | --- | --- |
| Схема | 2/2 | 2/2 |
| Полная проверка качества | 0/2 | 0/2 |
| Правильные значения запрошенных фактов | 2/3 | 3/3 |
| Дословные уникальные цитаты | 9/10 | 14/14 |
| V02 | Верные факты и запрос подтверждений. Нет отправки формы в хронологии | Те же факты и пробел в хронологии. Появилась блокировка за повторное чтение и неверный тип источника |
| V04 | Неверный дубликат факта, пустая хронология, недословная цитата, повторное чтение | Верный факт, три события, оба подтверждения. В доказательстве отправки есть только заголовок `Date` |
| Всего токенов | 5067 | 7418 |
| Reasoning в составе completion | Groq не сообщил | 2048, по 1024 на ответ |

В V02 `read_source` указывает на уже включённый журнал поставщика. Оригинала
сообщения и квитанции в нём нет. Validator сохранил `wrong_lookup_kind` и
`repeated_snapshot_lookup`. Отправка формы в 12:09:55 по-прежнему отсутствует.

В V04 смысл и времена всех трёх событий верны. Для отправки в 12:25 модель
процитировала только заголовок исходного письма. Сам фрагмент не связывает это
время с ответом клиента, а доказательства из события получения не переносятся
в событие отправки. Это тот же критерий, по которому оценивалась цитата
`Date` в [прогоне GPT-OSS](live-acceptance-groq-chat-2026-11-17.md).

При `medium` V04 заметно лучше, V02 хуже по следующему действию, расход токенов
выше на 46%. По одному ответу на условие причинный эффект и повторяемость
не установлены.

[Архив](../evals/live/v5-groq-qwen-medium-2026-11-17/manifest.json) содержит
оба исходных ответа, snapshot, usage, проверки приложения и оценки по кейсам.
Verifier подтвердил 16 хешей артефактов, два уникальных ответа провайдера,
хеши запросов и соответствие карточек исходным ответам. Live выключен,
ключ удалён из runtime, новый проект остановлен с сохранением собственной БД.
Операторских решений нет. Совпали хеши 144 защищённых файлов и пяти прежних томов,
а также состояния десяти защищённых контейнеров.

# Контроль V01 с двумя цитатами из письма

Для тестового V01 с проверенным письмом схема разрешает событие отправки предложения в указанное в письме время. В событии нужны две цитаты из этого письма: отметка отправки и сам текст предложения. Повтор одного ID отклоняет декодер. Офлайн сверены все шесть запросов. Изменилась только форма события отправки в V01. Локальный Ajv отклонил ответ v42 с заголовком и временем и пропустил ответы с обеими нужными цитатами. [Офлайн-проверка](../evals/live/v43-groq-gpt-oss-20b-v01-offer-pair-control-2026-11-24/offline-gpt-oss-verification.json).

В контроле v43 Groq вернул HTTP 400 `json_validate_failed` на этапе проверки сгенерированного ответа. Безопасная диагностика зафиксировала совпадающие верхнеуровневые поля и одно событие в отброшенном JSON. По этим данным нельзя установить, какое поле нарушило схему. Приложение сохранило неуспешный запуск, карточка не создана. Серия V01–V06 не запускалась. Этап 4 остаётся открытым. [Диагностика ответа](../evals/live/v43-groq-gpt-oss-20b-v01-offer-pair-control-2026-11-24/ablation-V01/wire.json), [результат контроля](../evals/live/v43-groq-gpt-oss-20b-v01-offer-pair-control-2026-11-24/summary.json).

Сделан один запрос к GPT‑OSS 20B на Groq Free с `reasoning_effort=low`. Бюджет $0, повторов ноль. Консоль не загрузилась при повторном открытии. Для допуска использовались сохранённое подтверждение Free, лимиты из предыдущего успешного ответа, учёт сделанных вызовов и запас на задержку статистики. Ответ v43 показал те же лимиты. Расход токенов в ответе не сообщён. [Сверка квоты](../evals/live/v43-groq-gpt-oss-20b-v01-offer-pair-control-2026-11-24/quota-console.json).

# Выбор цитат по ID

Офлайн-прототип от 18 ноября 2026 года. Из каждой включённой версии
источника берутся полные непустые строки, которые встречаются в ней ровно
один раз. Строка получает ID, связанный со снимком и границами цитаты.
Модель видит текст строк с ID. В её ответе `evidence` содержит выбранные
ID. Приложение собирает обычную карточку `assembly-output-v1`, копируя текст
по сохранённым границам из исходной версии источника.

Прототип использует отдельную схему ответа модели. Ограничения на факты,
события и вопросы взяты из соответствующего записанного запроса. В
публичной карточке по-прежнему хранятся тексты цитат и ID источников.

| Обращение | Записанная карточка | Карточка с вручную выбранными ID |
| --- | --- | --- |
| [V04](../../evals/live/v11-groq-qwen-same-document-v04-2026-11-18/full-V04/review.json) | 9 из 10 цитат дословны, одобрение заблокировано | 8 из 8 цитат дословны. Отправка подтверждена заголовком и текстом ответа, получение — строкой журнала. Остались вопросы про тихий номер и окна во двор. |
| [V02](../../evals/live/v8-groq-qwen-choices-v02-v04-2026-11-17/full-V02/review.json) | 7 из 11 цитат дословны, одобрение заблокировано | 10 из 10 цитат дословны. Отмена подтверждена строкой журнала. Остались запросы на исходное сообщение и подтверждение доставки. |

Обе собранные карточки дошли до проверки оператором. Значения фактов,
время и роли событий, готовность и вопросы совпали с записанными ответами.
В каждом случае каталог дал 10 вариантов. ID выбирались вручную. Проверка
подтверждает возможность собрать карточку с нужными цитатами из такого
каталога. Тело каждого запроса выросло на 907 байт. Новых модельных вызовов — 0.

Локальная проверка схемы и сборщик отклонили неизвестный ID и ID другого
обращения. При смене версии каталог старого снимка отклонён. Исключённый
источник не получил ID. В отрицательной проверке V04 схема приняла
дословный ID строки о получении в событии отправки. Проверка событий
обнаружила, что у отправки отсутствует цитата из самого ответа.

Запуск из корня репозитория с установленными Python-зависимостями и
зависимостями frontend из lockfile:

```sh
uv run --locked --offline python -B -X utf8 scripts/prototype_citation_ids.py
```

Формат подключён к отдельному профилю `v3.3-citation-ids-test`. Проверка
на PostgreSQL с подставным HTTP-ответом покрывает V04 и V02, проверяет
временную схему и раздельное сохранение исходного ответа и карточки.
[Настройка профиля](../live-provider.md#отдельная-проверка-id-цитат).

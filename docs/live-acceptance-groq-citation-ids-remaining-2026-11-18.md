# Live-проверка V03, V05 и V06 с ID цитат

18 ноября 2026 года. Groq Free, `qwen/qwen3.8-27b` с `medium`,
профиль `v3.3-citation-ids-test`, бюджет $0. Для каждого случая сверены
факты, достаточность цитат, хронология и следующий шаг по замороженному
эталону V3. Первичная серия выполнила по одному запросу на полный снимок.

| Кейс | Первичная серия | Контроль с проверенными событиями |
| --- | --- | --- |
| V03 | Полный проход. Подтверждено зачисление возврата, присутствуют списание, запуск возврата и зачисление. Дословны 14 из 14 цитат. | Полный результат получен в первичной серии. |
| V05 | Верны факт и доказательства получения отказа до отмены. Хронология пустая. | Полный проход. Отправка в 09:26, получение отказа в 09:30, отмена в 10:00. Дословны 12 из 12 цитат. |
| V06 | Верны подтверждённая отмена и снятие резерва, все 5 цитат дословны. Хронология пустая. | Groq вернул HTTP 429. Карточки контрольного прогона нет. |

В контрольной серии использован уже проверенный на V02 пример хронологии
с ID. По два проверенных события для V05 и V06 привязаны к текущим версиям
источников и используются в проверке приложения. Данные и схема совпали
с первичной серией после сопоставления новых ID. Лимит ответа установлен
в 3072 токена для запаса в минутной квоте.

После 429 серия завершена. Между контрольными вызовами прошло 65,26 секунды.
В отказе Groq сообщил остаток 999 запросов в дневном окне и 8000 токенов в
минутном. По этим заголовкам конкретный сработавший лимит определить не
удалось. За пять отправок Groq сообщил 19 565 токенов по четырём ответам.
Расход отклонённого запроса неизвестен. [Описание заголовков Groq](https://console.groq.com/docs/rate-limits).

В офлайн-контроле V06 выбраны ID строки об отмене, записи о снятии резерва
и записи об отсутствии списания. Карточка с двумя событиями прошла
валидацию, а пустая хронология получила блокирующую ошибку. Этот контроль
использовал ручной выбор ID и сделал ноль модельных вызовов.
[Офлайн-квитанция](../evals/live/v20-groq-qwen-timeline-v05-v06-2026-11-18/offline-check-v06.json).

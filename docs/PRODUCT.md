# Product

## Register

product

## Users

A single local demo operator reviewing synthetic travel cases, reading source documents and checking evidence before recording a decision. Repository visitors should be able to follow the complete workflow without model credentials.

## Product Purpose

Prepare facts, chronology and missing confirmations for human review. Make model errors inspectable and operator corrections traceable. Source text, model proposals, code checks and human decisions have separate provenance.

## Brand Personality

Precise, calm, candid. Russian task-oriented UI; technical identifiers appear in expandable details. Replay is labelled as a recorded response.

## Anti-references

Financial approval dashboards, conversational assistants, decorative KPI grids and a raw JSON editor as the primary review interface would obscure the actual task.

## Design Principles

- Put an evidence fragment beside its original source version.
- Give every consequential action an explicit label and visible outcome.
- Preserve historical context when the current case changes.
- Explain missing evidence and blocked actions in actionable language.
- Keep the workflow bounded to preparing a review, with no external execution.

## Accessibility & Inclusion

Use semantic headings, labelled native controls, keyboard navigation, visible focus, textual status labels, reduced-motion support and responsive panels. Target WCAG 2.2 AA contrast and reflow; include emoji and HTML-like source text in tests.
